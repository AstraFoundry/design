## 同心

内圆角 = 外圆角 − 内边距。面板 28px、内边距 8px，里面 40px 高的胶囊正好 20px；弹层 14px、内边距 4px，行是 10px。内边距大于外圆角时，内部元素保留自己的圆角。

## 连续曲率

`rounded-continuous-*` 在支持 `corner-shape: squircle` 的浏览器上画出苹果式的连续曲率圆角，其它浏览器保持四分之一圆。面板和卡片使用连续曲率圆角，胶囊使用 `rounded-full`。

## 间距与线

尺寸以 4px 为步长。线都是 1px `--border`：单元格之间用 1px 间隙露出底色来分格，保持线条始终是单层 1px，转角也干净闭合。

## 控件高度

| 尺寸 | 高度 | 用途                   |
| ---- | ---- | ---------------------- |
| sm   | 32px | 工具栏、表格内、紧凑行 |
| md   | 40px | 默认                   |
| lg   | 48px | 首屏主操作、移动端     |
