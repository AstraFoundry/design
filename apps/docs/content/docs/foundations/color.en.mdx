Every color is a semantic token. A `.dark` class switches the whole set at once; components never write physical colors.

## Yellow

<TokenSwatches names={["primary", "ring", "accent", "accent-foreground"]} />

`--primary` fills the one primary action or result on a screen; `--ring` is the keyboard focus ring. Chosen, on and checked use `--foreground`, not yellow.

## Status

<TokenSwatches names={["success", "danger", "info"]} />

Status colors mark dots and icons only, never running text. An error is ink text with a red dot.
