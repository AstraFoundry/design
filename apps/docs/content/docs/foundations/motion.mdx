## 曲线

| Token           | 曲线                             | 用途                                 |
| --------------- | -------------------------------- | ------------------------------------ |
| `--ease-out`    | `cubic-bezier(.22, 1, .36, 1)`   | 进入或移动的东西；离开               |
| `--ease-spring` | `cubic-bezier(.34, 1.4, .64, 1)` | 小东西出现、开关的档位、浮层弹出     |
| `--ease-in-out` | `cubic-bezier(.65, 0, .35, 1)`   | 已在屏上的东西改变形状：指示器、折叠 |
| `--ease-drawer` | `cubic-bezier(.32, .72, 0, 1)`   | 抽屉与 sheet                         |

时长来自 `sunbeam.json` 的 `motion`，生成为 CSS 变量 `--duration-*` 和 Go 常量 `sunbeam.Duration*`。

## 规则

- 每次输入 100ms 内有可见反馈。
- 离开比进入快。只动 `transform`、`opacity`、`filter`（折叠的 `height` 是唯一例外）。
- 浮层从触发点（`--transform-origin`）长出，而不是从屏幕中心。
- 场景被看到时播一次，停在结果上。只有真实等待才循环（Spinner、Skeleton）。
- 开启减少动态效果时，直接显示终态。
