## Curves

| Token           | Curve                            | Use                                                        |
| --------------- | -------------------------------- | ---------------------------------------------------------- |
| `--ease-out`    | `cubic-bezier(.22, 1, .36, 1)`   | Anything entering or moving; leaving                       |
| `--ease-spring` | `cubic-bezier(.34, 1.4, .64, 1)` | Small things appearing, a switch's detent, popups          |
| `--ease-in-out` | `cubic-bezier(.65, 0, .35, 1)`   | Something on screen changing shape: indicators, disclosure |
| `--ease-drawer` | `cubic-bezier(.32, .72, 0, 1)`   | Drawers and sheets                                         |

Durations live in `motion` in `sunbeam.json` and generate the CSS variables `--duration-*` and the Go constants `sunbeam.Duration*`.

## Rules

- Every input answers visibly within 100ms.
- Exits are faster than entrances. Animate `transform`, `opacity` and `filter` (and `height` for disclosure, the one exception).
- Popups grow from their trigger (`--transform-origin`), not the screen's center.
- A scene plays once when it is seen and rests on its result. Only real waiting loops (Spinner, Skeleton).
- With reduced motion, show the final frame.
