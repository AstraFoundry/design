- 标题用 Fraunces 400，从不加粗、不用斜体强调。展示字号随视口在 48–96px 间缩放。
- 中文和日文回落到系统字体（苹方、冬青、Noto），标题不加字距。
- 变化或需要对齐的数字用 `tabular-nums`。标题 `text-balance`，段落 `text-pretty`，每行不超过约 65 个字符。
- 句首大写（英文），不用感叹号和 emoji。
