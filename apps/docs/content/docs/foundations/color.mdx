所有颜色都是语义 token，亮暗两套由 `.dark` 一次切换，组件全部使用语义 token。

## 黄

<TokenSwatches names={["primary", "ring", "accent", "accent-foreground"]} />

`--primary` 只填充一屏中唯一的主操作或结果；`--ring` 是键盘焦点环。选中、开启、勾选一律用 `--foreground`。

## 状态

<TokenSwatches names={["success", "danger", "info"]} />

状态色专用于圆点和图标。错误提示是墨色文字加一个红点。
