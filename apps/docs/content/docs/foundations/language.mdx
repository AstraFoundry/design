Sunbeam 为高效交互服务。它的语言由两层叠成：界面这一层清晰、明快、精确；背景那一层用印象派式的照片给出人文主义的摩擦感。两层各司其职，互不侵入。

## 明

状态靠对比和形体表达，不靠颜色堆叠。选中、开启、勾选用墨色实心；黄色只留给一屏中唯一的主操作或结果。一眼看去，最重要的东西是黄的，其次是墨色的，其余都退后。

## 动

每次输入都在 100ms 内给出可见反馈：按下下沉到 0.97，开关的旋钮带一点过冲落进档位，浮层从触发点用 spring 长出。见 [动效](./motion)。

## 轻快

浮层进场 160–240ms，出场比进场快约 40%。没有装饰性的入场动画，也没有循环——唯一的例外是表示真实等待的 Spinner 和 Skeleton。

## 摩擦

只出现在照片里：动态模糊的自然照片放在首屏、空状态、引导页和产品演示的舞台下。照片上只有一个实心的焦点面，其余是半透明的色块或被边缘裁掉。组件本身不加纹理、颗粒，也不仿纸。见 [照片](./photographs)。

## 平面与轻拟物并行

同一门语言的两种材质，按层使用，不按组件挑选：页面和窗口外框是平面；浮在上面的层是浮起（轻拟物）。见 [材质](./material)。
