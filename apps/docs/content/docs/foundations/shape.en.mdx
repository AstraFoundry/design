## Concentric

Inner radius = outer radius − inset. A 28px panel with an 8px inset holds 40px pills at 20px; a 14px popup with a 4px inset holds 10px rows. When the inset is larger than the outer radius, the inner element keeps its own radius.

## Continuous corners

`rounded-continuous-*` draws Apple-style continuous corners where the browser supports `corner-shape: squircle`, and quarter circles elsewhere. Use it on panels and cards, not pills.

## Spacing and lines

Sizes step by 4px. Lines are 1px `--border`: show the border color through a 1px gap between cells instead of a border on each, so lines never double and corners never break.

## Control heights

| Size | Height | Use                              |
| ---- | ------ | -------------------------------- |
| sm   | 32px   | Toolbars, table rows, dense rows |
| md   | 40px   | The default                      |
| lg   | 48px   | A hero's primary action, mobile  |
