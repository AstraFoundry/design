Sunbeam 让人和 agent 都能很快把事情做完。界面本身清晰、明快：反馈来得快，状态一眼看清，每屏只有一处黄。人文主义的摩擦感交给背景——印象派式、动态模糊的自然照片——叠在照片上的 UI 不带纹理，也不怀旧。

## 四件事

<Steps>
  <Step>
    **墨色，一抹黄。**
    中性色是暖墨。黄色只标记一屏中唯一的主操作或结果，选中、开启、勾选都用墨色。
  </Step>
  <Step>
    **平面与浮起并行。**
    页面和窗口外框是平面；浮在上面的层（面板、弹层、菜单、对话框）是浮起材质，层里的控件跟着浮起。材质跟着层走，不跟着组件走。
  </Step>
  <Step>
    **同心圆角。** 内圆角 = 外圆角 − 内边距。28px 的面板减 8px 内边距，正好是 40px 胶囊的
    20px。
  </Step>
  <Step>
    **动效快而有落点。** 输入在 100ms 内有回应；浮层从触发点用 spring
    长出，离开更快；场景播一次就停在结果上。
  </Step>
</Steps>

## 安装

```sh
pnpm add @astrafoundry/design @base-ui/react
```

```css title="app/globals.css"
@import "tailwindcss";
@import "@astrafoundry/design/styles.css";
```

```tsx
import { Button, Panel } from "@astrafoundry/design/ui";
```

组件只用语义 token，不写物理颜色和 `dark:`。亮暗模式由 `<html>` 上的 `.dark` 类切换。所有可见文案都从 props 传入，组件里没有默认英文。

## 与其它系统的关系

Sunbeam 的交互原语来自 [Base UI](https://base-ui.com)，组件覆盖面对齐 [coss ui](https://coss.com/ui) 与 [Vercel UI SDK](https://github.com/vercel-labs/ui)，文字和 Agent 动效来自 [beUI](https://beui.dev)。同一套 token 与组件也以 Go 实现，供 [MyGo](https://github.com/egoist/mygo) 绘制原生窗口。
