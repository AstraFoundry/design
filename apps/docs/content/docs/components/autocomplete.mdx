## 引入

```tsx
import { Autocomplete } from "@astrafoundry/design/ui";
```

## 何时使用

标签、搜索词。

## 换用这个

必须从列表中选：用 Combobox。

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。
