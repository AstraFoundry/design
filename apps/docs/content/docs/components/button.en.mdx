## Import

```tsx
import { Button } from "@astrafoundry/design/ui";
```

## When to use

Submitting, saving, creating: anything that takes effect now.

## When not to

Going to another page: use LinkButton or a link.

## Material

On a flat layer it is a fill; inside a Panel or any `data-material="raised"` layer it is raised, by itself. Flip the material switch at the demo's top right to compare.
