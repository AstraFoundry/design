## 引入

```tsx
import { RadioGroup } from "@astrafoundry/design/ui";
```

## 何时使用

表单里 2–6 个互斥选项。

## 何时不用

选项很多：用 Select。

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。
