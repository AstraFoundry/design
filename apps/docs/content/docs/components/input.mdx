## 引入

```tsx
import { Input } from "@astrafoundry/design/ui";
```

## 何时使用

名称、邮箱、搜索等单行文本。

## 换用这个

多行文本：用 Textarea。

## 示例

<Demo name="input/sizes" />

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。
