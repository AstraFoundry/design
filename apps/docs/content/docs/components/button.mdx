## 引入

```tsx
import { Button } from "@astrafoundry/design/ui";
```

## 何时使用

提交、保存、创建——任何立即生效的动作。

## 何时不用

跳转到别的页面：用 LinkButton 或链接。

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。
