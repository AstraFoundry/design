## 引入

```tsx
import { OTPField } from "@astrafoundry/design/ui";
```

## 何时使用

登录与两步验证。

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。

## 动效

<MotionTable
