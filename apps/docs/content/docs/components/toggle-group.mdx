## 引入

```tsx
import { ToggleGroup } from "@astrafoundry/design/ui";
```

## 何时使用

对齐方式、视图模式等少量互斥或可多选的选项。

## 何时不用

表单中的单选：用 RadioGroup。

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。
