## Import

```tsx
import { Combobox } from "@astrafoundry/design/ui";
```

## When to use

Long lists: time zones, countries, people.

## When not to

Free text with suggestions: use Autocomplete.

## Material

On a flat layer it is a fill; inside a Panel or any `data-material="raised"` layer it is raised, by itself. Flip the material switch at the demo's top right to compare.
