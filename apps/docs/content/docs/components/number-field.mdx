## 引入

```tsx
import { NumberField } from "@astrafoundry/design/ui";
```

## 何时使用

数量、座位数等有步长的整数。

## 何时不用

很大的范围：用 Slider 或 Input。

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。
