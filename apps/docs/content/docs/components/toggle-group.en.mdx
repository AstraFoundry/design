## Import

```tsx
import { ToggleGroup } from "@astrafoundry/design/ui";
```

## When to use

A few exclusive or combinable options, as alignment.

## When not to

A choice in a form: use RadioGroup.

## Material

On a flat layer it is a fill; inside a Panel or any `data-material="raised"` layer it is raised, by itself. Flip the material switch at the demo's top right to compare.
