## Import

```tsx
import { Segmented } from "@astrafoundry/design/ui";
```

## When to use

Switching between 2–5 exclusive views.

## When not to

Navigating to other pages: use Tabs or links.

## Material

On a flat layer it is a fill; inside a Panel or any `data-material="raised"` layer it is raised, by itself. Flip the material switch at the demo's top right to compare.
