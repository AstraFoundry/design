## 引入

```tsx
import { Switch } from "@astrafoundry/design/ui";
```

## 何时使用

立即生效的设置。

## 何时不用

需要提交才生效的选择：用 Checkbox。

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。
