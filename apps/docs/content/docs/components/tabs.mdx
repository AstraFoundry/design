<Demo name="tabs/underline" />

## 引入

```tsx
import { Tabs } from "@astrafoundry/design/ui";
```

## 何时使用

设置分区、详情的各个切面。

## 换用这个

导航到别的页面：用链接。

## 示例

<Demo name="tabs/segmented" material />

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。
