---

<Demo name="autocomplete/basic" material />

## Import

```tsx
import { Autocomplete } from "@astrafoundry/design/ui";
```

## When to use

Tags, search terms.

## Use this instead

When the value must come from the list: use Combobox.

## Material

On a flat layer it is a fill; inside a Panel or any `data-material="raised"` layer it is raised, by itself. Flip the material switch at the demo's top right to compare.
