## Import

```tsx
import { Tabs } from "@astrafoundry/design/ui";
```

## When to use

Settings sections, facets of a record.

## When not to

Going to other pages: use links.

## Examples

<Demo name="tabs/segmented" material />

## Material

On a flat layer it is a fill; inside a Panel or any `data-material="raised"` layer it is raised, by itself. Flip the material switch at the demo's top right to compare.
