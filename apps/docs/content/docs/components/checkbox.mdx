## 引入

```tsx
import { Checkbox } from "@astrafoundry/design/ui";
```

## 何时使用

多选、同意条款、单个开关项。

## 何时不用

立即生效的设置：用 Switch。

## 示例

<Demo name="checkbox/indeterminate" />

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。
