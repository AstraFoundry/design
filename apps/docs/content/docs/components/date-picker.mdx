## 引入

```tsx
import { Calendar, DatePicker } from "@astrafoundry/design/ui/calendar";
```

```sh
pnpm add react-day-picker
```

## 何时使用

表单里的单个日期。

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。
