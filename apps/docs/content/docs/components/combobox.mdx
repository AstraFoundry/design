## 引入

```tsx
import { Combobox } from "@astrafoundry/design/ui";
```

## 何时使用

时区、国家、成员等长列表。

## 换用这个

自由文本加建议：用 Autocomplete。

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。
