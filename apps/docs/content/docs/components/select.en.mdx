<Demo name="select/basic" material />

## Import

```tsx
import { Select } from "@astrafoundry/design/ui";
```

## When to use

5–15 options.

## When not to

Long lists that need search: use Combobox.

## Examples

<Demo name="select/groups" />

## Material

On a flat layer it is a fill; inside a Panel or any `data-material="raised"` layer it is raised, by itself. Flip the material switch at the demo's top right to compare.
