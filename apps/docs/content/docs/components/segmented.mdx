## 引入

```tsx
import { Segmented } from "@astrafoundry/design/ui";
```

## 何时使用

2–5 个互斥视图之间切换。

## 换用这个

导航到别的页面：用 Tabs 或链接。

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。

## 滑动的选中面

一组等宽分段只有一个浮起的选中面，选择改变时它用 spring 滑到新位置，像落进档位一样停下。自己写分段轨道时用 `SegmentThumb`：

```tsx
<div className="material-well relative isolate inline-grid auto-cols-fr grid-flow-col gap-1 rounded-full p-1">
  <SegmentThumb index={chosen} count={options.length} className="-z-10" />
  {/* 分段按钮，本身不带面 */}
</div>
```
