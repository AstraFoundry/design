## 引入

```tsx
import { Menu } from "@astrafoundry/design/ui";
```

## 何时使用

对一个对象的一组动作。

## 换用这个

选值：用 Select。

## 子菜单与安全三角

打开子菜单后，指针从触发项斜向移往子菜单的途中，触发项保持高亮、子菜单保持展开（Base UI 的 `safePolygon`）。在别的菜单项上停留，或者明显偏离路径，才会切换过去。MyGo 的 `sunbeam.Menu` 用同样的规则，停留 300ms 后切换。
