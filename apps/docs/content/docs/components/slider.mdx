## 引入

```tsx
import { Slider } from "@astrafoundry/design/ui";
```

## 何时使用

音量、价格区间等连续值。

## 何时不用

精确数字：用 NumberField。

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。
