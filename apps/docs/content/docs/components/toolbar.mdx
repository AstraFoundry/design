## 引入

```tsx
import { Toolbar } from "@astrafoundry/design/ui";
```

## 何时使用

编辑器格式栏、画布工具栏。

## 换用这个

浮层里的一组操作：直接放按钮。

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。
