## Import

```tsx
import { Menu } from "@astrafoundry/design/ui";
```

## When to use

Actions on one object.

## Use this instead

Choosing a value: use Select.

## Submenus and the safe triangle

With a submenu open, a pointer moving diagonally toward it crosses the rows in between while the trigger keeps its highlight and the submenu stays open (Base UI's `safePolygon`). Resting on another row, or veering away, switches to it. MyGo's `sunbeam.Menu` keeps the same rule and switches after a 300ms rest.
