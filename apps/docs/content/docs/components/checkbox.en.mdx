```tsx
import { Checkbox } from "@astrafoundry/design/ui";
```

## When to use

Several choices, agreements.

## Use this instead

Settings that take effect at once: use Switch.

## Examples

<Demo name="checkbox/indeterminate" />

## Material

On a flat layer it is a fill; inside a Panel or any `data-material="raised"` layer it is raised, by itself. Flip the material switch at the demo's top right to compare.
