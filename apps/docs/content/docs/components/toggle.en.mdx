## Import

```tsx
import { Toggle } from "@astrafoundry/design/ui";
```

## When to use

Turning a format or view on and off, as bold.

## Use this instead

A setting that turns on and off: use Switch.

## Material

On a flat layer it is a fill; inside a Panel or any `data-material="raised"` layer it is raised, by itself. Flip the material switch at the demo's top right to compare.
