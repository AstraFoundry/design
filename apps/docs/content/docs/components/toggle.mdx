## 引入

```tsx
import { Toggle } from "@astrafoundry/design/ui";
```

## 何时使用

开关某种格式或视图，例如粗体。

## 何时不用

设置项的开关：用 Switch。

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。
