<Demo name="select/basic" material />

## 引入

```tsx
import { Select } from "@astrafoundry/design/ui";
```

## 何时使用

5–15 个选项。

## 何时不用

需要搜索的长列表：用 Combobox。

## 示例

<Demo name="select/groups" />

## 材质

平面层里它是一层填充；放进 Panel 或任何 `data-material="raised"` 的层，它会自动浮起。切换示例右上角的材质按钮对比。
