## Import

```tsx
import { Toolbar } from "@astrafoundry/design/ui";
```

## When to use

An editor's format bar, a canvas's tools.

## When not to

Actions inside a floating layer: use buttons directly.

## Material

On a flat layer it is a fill; inside a Panel or any `data-material="raised"` layer it is raised, by itself. Flip the material switch at the demo's top right to compare.
